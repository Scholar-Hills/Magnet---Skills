# 成品壳保证什么、不保证什么

`deck.html`（投屏）与 `notes.html`（教师讲稿）都由 `build` 从 `pages/` 派生，壳的全部实现就在 `scripts/lessonkit.py` 里，零依赖、零外链、单文件。**这份文件说清楚它承诺了什么、明确不承诺什么**，免得老师带着错误的预期走进教室。

契约改动与脚本、selftest 同 commit（母仓 §4）。

## 1. 保证的部分

### 1.1 画布与缩放

- 每页是一个 `1280 × 720` 的白底画布（16:9），页内 72px / 56px 的边距围出 `1136 × 608` 的内容区。
- **两级等比缩放**，都由壳自己的脚本在运行时算：
  - **外层**：整页按舞台大小等比缩放居中，比例取 `min(舞台宽/1280, 舞台高/720)`，**封顶 1**——窗口再大也不会把页放大到失真。
  - **内层**：如果这一页的内容比内容区高，`.fit` 那一层会按 `内容区高 / 实际高` 缩下去，**最小 0.5**。
- 窗口大小变化时两级都会重算。

### 1.2 翻页

| 按键 | 动作 |
|---|---|
| `→` `↓` `PageDown` `空格` | 下一页 |
| `←` `↑` `PageUp` | 上一页 |
| `Home` | 第一页 |
| `End` | 最后一页 |

右下角的页码条实时显示「当前 / 总页数」。翻页与页码都按 `.slide` 认页——这就是页稿不许再用那 13 个壳保留类名的原因，见 `references/workflow-rules.md` §6。

### 1.3 打印成 16:9 的 PDF

壳自带 `@page{size:13.333in 7.5in;margin:0;}`——13.333 × 7.5 英寸正好是 16:9。打印时脚本会把所有页都显示出来、逐页重算内缩、每页一张，打完再回到你刚才那一页。

**Chrome / Edge**：打开 `deck.html` → `Ctrl/Cmd + P` → 目标选「另存为 PDF」→ 展开「更多设置」→ 边距设为「无」、勾选「背景图形」→ 保存。纸张方向不用管，`@page` 已经把尺寸定死了。

**Safari**：文件 → 打印 → 左下角「PDF」→「存储为 PDF」。Safari 对 `@page size` 的支持较弱，若出来的是 A4，就在「纸张大小」里自定义 13.333 × 7.5 英寸。

`notes.html` 同样可以打印：一页一行，每行不会被跨页切断，打印时去掉灰底与圆角，直接就是一份能带上讲台的稿子。

### 1.4 主题色

八个 key 与 hex（未知 key 回落 `cyan` 并给 WARN）：

| key | hex | key | hex |
|---|---|---|---|
| `cyan`（默认） | `#0891b2` | `violet` | `#7c3aed` |
| `indigo` | `#4f46e5` | `slate` | `#475569` |
| `emerald` | `#059669` | `teal` | `#0d9488` |
| `amber` | `#d97706` | `rose` | `#e11d48` |

- 整份成品里，主题色只出现在一行上：`:root{--accent:#xxxxxx;}`。
- 壳的默认样式让 **`h1`、`h2`、`th`、`blockquote`** 直接吃 `var(--accent)`。所以一页纯文字、页稿里一个颜色都没写，换色照样看得出来。
- `build` 会把页稿 `style` 里写死的八色任一 hex（大小写不敏感）换回 `var(--accent)`。
- `repalette <slug> --palette <key>` **只重拼成品**：跑完 `pages/` 下每个文件逐字节不变，新旧 `deck.html` 的差异只在 `:root{--accent}` 那一行。这条由 selftest 断言。

### 1.5 讲稿绝不进投屏

- `notes.html` 每页一行：左边是同一页缩到 480 × 270 的缩略（同一套壳，缩放 0.375），右边是讲稿；行首写着「第几页 / 共几页 · 页 id · 页名」，页首固定一句「**教师讲稿 · 不投屏**」。
- `deck.html` 里**没有任何讲稿文本**。`build` 会逐页断言「这一页讲稿的前 40 字不出现在 `deck.html` 里」，不过就不写成品。
- `notes.html` 里**没有脚本**（`<script` 出现即判死）；`deck.html` 里恰好一个（翻页与缩放），且没有 `<svg`。

### 1.6 自包含

- 无外链：`deck.html` 与 `notes.html` 里任何属性值出现 `http://`、`https://` 或协议相对 `//`（合法的 `data:image` 内嵌图除外）都是 ERROR——判据与页稿准入是同一条、不按 `src=` / `url(` 的写法枚举，见 §2.7。教室断网也照常放。
- 无品牌、无 logo、无页眉。这是一个空壳，上面只有老师的内容。
- 字体走系统字体栈（`-apple-system` / `Segoe UI` / `PingFang SC` / `Microsoft YaHei` 一路兜底），不下载任何字体文件。

### 1.7 `build` 会自己兜的壳级断言

`deck.html` 里必须有 `width:1280px;height:720px`、`.fit{width:100%;transform-origin:top left;}`、`@page{size:13.333in 7.5in;margin:0;}`、`:root{--accent:#xxxxxx;}`；`<script` 恰好一次；没有 `<svg`；`data-page-id` 与 `class="slide"` 的出现次数都等于成品页数。任何一条不成立，`build` 判死、不写成品——**这是脚本自己防自己改坏壳的那道闸。**

## 2. 不保证的部分

### 2.1 不保证一定不溢出

内层缩放的**下限是 0.5**。一页内容多到缩一半还装不下，超出的部分就是被裁掉的，投屏时看不见，打印出来也没有。

密度闸（350 字 WARN / 1000 字 ERROR）是按 CSS 推算的启发式，**它是提醒，不是保证**。真正的保证只有一条：`build` 之后自己打开 `deck.html` 翻一遍。

### 2.2 不保证观感与版式

壳只做「排得下、看得清、能换色」这三件事。**没有第二遍自由排版，没有风格模板，没有配图。** 一页长什么样，取决于页稿里写了什么标签。想要好看，靠的是页稿本身写得克制：一个 `h2` 加三到五条 `li`，比一大段 `p` 好看得多。

### 2.3 不保证跨机器逐像素一致

系统字体栈意味着同一页在 macOS、Windows、投影仪自带的浏览器上，字宽与折行会有差别。**上课用的那台机器，课前一定要自己打开翻一遍**——特别是接了投影仪、分辨率被改过的时候。

### 2.4 不保证深色环境下的对比度

页底是白的，投在暗教室里会很亮。八个主题色都是在白底上选的，没有深色版。要暗底，本 Skill 目前给不了。

### 2.5 不导出 PPTX

只有 HTML 和浏览器打印出来的 PDF。**没有 `.pptx`**，也不打算有：一旦要导 PPTX，就得处理字体嵌入、文本框换算、图形降级这一整摊，那是另一个项目。

### 2.6 消毒不是准入的替代

`build` 会对每页做一遍消毒，重拼出一份只含白名单标签与排版属性的 HTML，顺手把标签配平。**它的定位是版面事故的兜底，不是准入闸的替代。** 实测行为：

| 页稿写法 | 消毒之后 |
|---|---|
| `<div><p>甲</p><p>乙</p>`（未闭合） | `<div><p>甲</p><p>乙</p></div>`，**补齐到本页结尾，不会跨页** |
| `<div><p>甲</div>乙</p>丙`（多余闭合） | `<div><p>甲</p></div>乙丙`，多余的闭合标签丢掉，文字全留 |
| `<div><strong>甲<p>乙</strong>丙</p></div>`（交叉嵌套） | `<div><strong>甲<p>乙</p></strong>丙</div>`，**「丙」被抬到了 `p` 外面** |
| `<section><div>甲</section>乙`（白名单外容器包着未闭合内层） | `<div>甲乙</div>`，**「乙」被吞进了 `div`** |

最后一行是要点名的边界：**一个被丢弃的容器，会让它里面没闭合的那一层把后面的文字吞进去。** 文字不会丢，但结构错位，投出来的版式跟你写的不是一回事。

好在这类页在准入阶段就已经判死了（`section` 不在白名单里），根本到不了 `build`。**所以：不要指望消毒替你收拾页稿，标签该配平就配平。**

### 2.7 外链判据从严：属性值里出现协议字样就拒，注释也不例外

页稿准入与成品复查用同一条外链判据：属性值先做 HTML 实体解码，再压掉空白、统一小写、抠掉合法 `data:image` 的 base64 载荷之后，出现 `http:`、`https:` 或协议相对 `//` 即 ERROR。**不按函数名枚举**——`url()`、`image-set()`、`cross-fade()`、`-webkit-image-set()`、`image()` 一视同仁。样式值经实体解码后不接受反斜杠转义；出现即拒收。

代价是从严误伤：CSS 注释里写个网址（`style="/* 见 https://… */color:red"`）同样被拒。这是刻意的——属性里没有写网址的正当理由，网址请写进正文文字。详见 `references/workflow-rules.md` §5。

## 3. 怎么写页稿才用得上这套壳

- **一页一件事。** 一个 `h2` 起头，下面三到五条 `li` 或者两三段短 `p`。密度警戒线 350 字，超过就该拆页了。
- **标题用 `h1` / `h2`，重点用 `blockquote`，对照用 `table`。** 这四类壳会自动上主题色，换色时最看得出来。
- **不要写内联颜色。** 想要强调就用 `strong`；实在要上色，写 `var(--accent)`，别写死 hex。
- **不要用那 13 个壳保留类名**（`slide` `pad` `fit` `stage` `rail` `thumb` `talk` `row` `wrap` `say` `no` `hd` `sub`），也不要写 `data-page-id` / `data-talk-id`。
- **图片放 `assets/` 下**，用 `<img src="assets/xxx.png" alt="…">`；没有图就别留占位说明，那是 ERROR。
- **页稿是片段，不是文档。** 不要写 `<!DOCTYPE>` / `<html>` / `<head>` / `<body>`，壳会包。
