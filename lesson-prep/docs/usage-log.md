# 真课记录

这份表用来记录**用这份 Skill 备的真课**：一次一行，课上完当天填，不补记、不估算。

目前**还没有任何一行**——Skill 版本先行，记录随真课逐条补上。表里只写实际发生过的事；没跑过的不写，估的数字不写。

## 怎么填

- **日期**：这节课实际上课的日期，不是备课日期。
- **课时长**：`lesson.json` 里的 `minutes`。
- **四步耗时**：从 `init` 到 `check --all` 通过，四步各花了多久（分钟），写成 `课纲卡 / 作业 / 阶段 / 页稿`。中途去做别的事就把那段时间刨掉。
- **`check` 失败次数**：每一步 `check` 退出非 0 的次数合计，**并逐条写清楚卡在哪一条闸门**（例如「G7 覆盖 ×2：q3、q6 实词重合不足」）。这一列是这份表最有价值的部分——它告诉我们哪把锁最常撞、哪类题最常没讲到。
- **放映是否溢出**：`build` 之后在**实际上课那台机器**上翻一遍，有没有哪一页被裁掉。写「无」或者写具体是第几页。
- **是否改了脚本判死的页**：脚本判死之后，老师是照着改了内容，还是认为脚本判错了。判错要写清楚那一页当时长什么样——这是回调阈值的唯一依据。

## 阈值回调候选

跨模型实测与真课记录攒够之后，下面这几个阈值按误报率回调。**改一次就要在同一个 commit 里改 `scripts/lessonkit.py` 常量区、`references/workflow-rules.md` 与 `scripts/selftest.py`。**

| 常量 | 当前值 | 待观察的问题 |
|---|---|---|
| `TALK_PER_MINUTE` | 60 | 英文课按词计数，`课时 × 60` 是不是过严 |
| `OVERLAP_MIN` | 2 | 短题干（尤其是英文短题干）会不会误报「没讲到」 |
| `COPY_RATIO` | 0.8 | 术语密集的页，正常讲稿会不会被误判成抄正文 |
| `DENSITY_WARN` / `DENSITY_HARD` | 350 / 1000 | 英文页按词计数偏松，中文页 350 是不是偏严 |
| `SAT_WARN` | 0.25 | 非中性色 WARN 的误报率 |
| `PROMPT_MIN` / `SUMMARY_MIN` | 10 / 20 | 同样的中英文口径差 |
