# 远程办公者该怎么选城市

可以完全远程的人多了一项别人没有的自由：挑一座城市住下来，而不是被公司的地址挑中。自由随之带来一个新问题——按什么挑。本文的看法是，远程办公只是把「离公司多近」这一条从清单上划掉了，它并没有替你补上新的一条；原来被通勤挡在后面的那几条，现在得由你自己排序。

先算钱。省下的通勤时间是白得的，省下的房租不是——差价要乘满一年再看。一线城市一间单人公寓的年租，换到二线往往能租下一套两居，多出来的那间正好当书房；对全职远程的人，书房不是奢侈品，是工位。但水电、供暖、宽带、偶尔飞回总部的机票都得算进去，差价会缩水，缩多少因城而异。这笔账必须自己列，别信平均值。

第二件事是网络与它的替补。全职远程的人一年要开几百场会，家里的宽带断一次，损失的不只是那一场会的时间，还有对方对你可靠程度的判断。挑城市时值得花半天查两件事：这座城市的家庭宽带上行带宽是多少，以及方圆三公里内有没有一家可以随时进去坐下的付费办公空间。前者决定你日常的下限，后者决定你出事那天的下限。

第三条是时区，它比距离更能决定你的一天长什么样。团队在哪个时区，就决定了你每天有几个小时必须坐在桌前：跟你差六小时的团队，会都排在你的傍晚，白天完整地留给你；差十二小时的团队，则会把你的作息一点点拧成夜班。挑城市之前先把团队的固定会议时间摊在时区表上，看看它落在你的哪一段，再决定这座城市值不值得。这一条算错了，前面省下的房租会以睡眠的形式还回去。

第四条是把账算到一年，再问一句能不能反悔。押金、中介费、搬家、置办书房、第一年往返总部的机票，这些一次性支出摊到十二个月，会把看上去便宜一半的城市拉回到只便宜三成。更要紧的是退出成本：租约能不能转、押金拿不拿得回、如果三个月后发现不合适，回到原来的城市要付出什么。把这两个数字写在纸上，很多犹豫会当场消失——不是因为答案变好看了，而是因为它终于变成了一个可以算的数。

再往下是一条不好量化、却最容易让人搬走的：人。通勤取消的同时，同事也取消了。原来一天里那些不必约的碰面——一起下楼买咖啡、开会前的五分钟闲聊——在远程之后一件都不剩，得靠你自己重新造。所以挑城市时要看的不是这座城市有多少人口，而是有没有你能持续参加的固定场合：一个每周三晚上的球局、一间认识老板的书店、一个不必自我介绍就能坐下的桌子。这些东西搬不走，也不能远程。

最后一条最枯燥，也最容易在签合同之后才发现：手续。医保能不能异地结算、租房备案要不要工作证明、孩子上学看不看社保年限、如果你是跨境远程，签证允不允许你在当地长期居留并且合法纳税——这些条目单独看都不吓人，凑在一起却能把一座城市从名单上划掉。它们的共同点是查得到、也查得清，只是没人愿意在兴头上去查。

远程办公划掉了「离公司多近」，却没有补上任何一条新的。房租的年度差价、网络的下限、时区落在你一天的哪一段、退出时要付的成本、能不能长期参加的固定场合，还有那一堆枯燥的手续——它们原本都被通勤这条硬约束挡在后面，现在一起露了出来。挑城市从来不是找一个最好的，而是想清楚你打算为哪一条让步，以及让到什么程度为止。
