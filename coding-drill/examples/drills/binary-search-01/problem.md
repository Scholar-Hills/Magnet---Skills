# 有序数组里第一个不小于阈值的位置

一排学生按身高从矮到高站好，你要找出**第一个身高不低于阈值 goal 的人站在第几位**。

## 任务

给定一个非递减（可能有重复）的整数数组，找出**第一个大于或等于 goal 的元素**，输出它的位置。位置从 1 开始数。

## 输入格式

共三行：

1. 第一行一个整数 n（1 ≤ n ≤ 100），表示数组长度。
2. 第二行 n 个整数，用一个空格分隔，保证从左到右非递减（允许相等）。每个数在 0 到 100000 之间。
3. 第三行一个整数 goal，即阈值。

## 输出格式

一行：

- 如果存在不小于 goal 的元素，输出**第一个**这样的元素的位置（从 1 开始数的整数）。
- 如果数组里所有元素都小于 goal，输出 `NONE`（四个大写字母）。

## 并列规则

有多个元素都不小于 goal 时，输出**位置最小**的那一个；若有多个元素的值相等且都不小于 goal，同样取位置最小的那一个。注意 goal 本身出现在数组里时，它自己就是不小于 goal 的元素。

## 示例

输入：

```
5
10 20 30 40 50
30
```

输出：

```
3
```
