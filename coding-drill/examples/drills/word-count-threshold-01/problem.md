# 出现次数达标的单词有几个

一段讲稿被拆成了一串单词，编辑想知道：**有多少个不同的单词，出现次数达到了 k 次**。

## 任务

给定一串小写单词和一个阈值 k，统计**出现次数大于或等于 k 的不同单词有多少个**。注意数的是「不同的单词有几个」，不是这些单词一共出现了多少次。

## 输入格式

共三行：

1. 第一行一个整数 n（1 ≤ n ≤ 100），表示单词个数。
2. 第二行 n 个单词，用一个空格分隔。每个单词只由小写英文字母组成，长度不超过 12。
3. 第三行一个整数 k（1 ≤ k ≤ n），即阈值。

## 输出格式

一行：

- 如果有单词的出现次数达到 k 次，输出这样的**不同单词的个数**（一个整数）。
- 如果一个单词都没达到 k 次，输出 `NONE`（四个大写字母）。

## 并列规则

「达到 k 次」包含**恰好等于 k 次**的情况。同一个单词无论出现多少次都只算一个；不同单词之间没有先后之分，只数个数，不用管顺序。

## 示例

输入：

```
9
red blue red green blue red pink blue pink
2
```

输出：

```
3
```
